Comentarios en HTML

En HTML los comentario se escribe entre los signos <!-- y -->. Lo que esta adentro no se muestra en el navegador, pero si queda guardado en el codigo fuente.

Los comentarios sirven para dejar notas al programador o para esconder una parte del codigo de forma temporal sin tener que borrarla. Esto es muy util cuando se esta probando una pagina.

Primera lista ordenada. Pasos para crear una pagina HTML

  1. Abrir Visual Studio Code
  2. Crear un archivo con extension .html
  3. Escribir la estructura basica (DOCTYPE, html, head y body)
  4. Agregar el contenido dentro del body
  5. Guardar el archivo y abrirlo en el navegador
