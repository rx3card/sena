Primeros pasos con Python

Guia hecha por Oscar Rojas y Santiago Diaz para que un aprendiz nuevo del SENA pueda empezar a programar en Python desde cero. La idea es que pueda escribir su primer programa sin complicarse.

¿Que es Python?

Python es un lenguaje de programacion sencillo de leer y muy usado en desarrollo web, analisis de datos y automatizacion. Para nosotros los aprendices es una buena opcion para empezar porque la sintaxis es facil de entender.

Prepara tu entorno

Antes de escribir el primer programa hay que preparar el computador. Los pasos son los siguientes:

  1. Descargar Python desde la pagina oficial.
  2. Durante la instalacion marcar la casilla Add Python to PATH.
  3. Instalar un editor de codigo, por ejemplo Visual Studio Code.
  4. Abrir la terminal y escribir python --version para comprobar que quedo instalado.

Tu primer programa

Ya con todo instalado se puede escribir el primer programa. Crear un archivo llamado hola.py y adentro escribir la siguiente linea:

print("Hola, mundo")

Luego ejecutarlo en la terminal con python hola.py. Si en la pantalla aparece el mensaje Hola, mundo quiere decir que ya programaste en Python.

Conceptos basicos para practicar

Una vez corre el primer programa, estos son los temas que conviene practicar en orden para ir aprendiendo poco a poco:

  • Variables: guardan datos, por ejemplo nombre = "Ana".
  • Tipos de datos: texto, numeros enteros y decimales.
  • Condicionales: if, elif y else.
  • Ciclos: for y while.
  • Funciones: bloques de codigo que se pueden reutilizar.

Consejos finales

Lo mas importante al empezar es no rendirse si algo no funciona a la primera. Casi siempre el error esta en un detalle pequeño como una comilla o un parentesis. Leer el mensaje de error con calma ayuda bastante.
